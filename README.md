# NftCobalt

Employs Real-Time Processing and Auto-Scaling for High-Performance NFT data aggregation and querying on distributed Processor platforms.

The key benefits of using NftCobalt include:

- Employs Real-Time Processing and Auto-Scaling
- for High-Performance NFT data aggregation
- and querying on distributed Processor

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftCobalt.git`
2. `cd NftCobalt`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NftCobalt, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
